# Arsip arah cangkang B dan C

Jerome memilih arah A (seperti Zendenta) sebagai cangkang default dan satu-satunya.
File di folder ini **tidak diimpor** oleh aplikasi. `tsconfig.app.json` mengeksklusikan folder ini dari build.

- `JadwalShell.tsx` — prototipe saklar `#/jadwal?shell=a|b|c` (A/B/C).
- `shells-abc.css` — gaya ketiga arah saat masih dibandingkan di Jadwal saja.
