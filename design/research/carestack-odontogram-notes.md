# Catatan: CareStack "A Guide to the Odontogram" (dibaca 14 Nov 2026)
Sumber: https://carestack.zendesk.com/hc/en-us/articles/27732426396564-A-Guide-to-the-Odontogram
Ide pola saja, jangan salin UI.

- Status berlapis: tiap status punya warna; opsi transparansi agar beberapa tindakan/kondisi terlihat bertumpuk di satu gigi.
- Hover gigi: tooltip ringkas (kondisi + rencana/selesai).
- Rencana -> Selesai: visual gigi berubah. Gigi dicabut/hilang: tindakan lain disembunyikan.
- Kondisi aktif/nonaktif: kondisi nonaktif hilang dari bagan, tetap ada di riwayat.
- Gigi supernumerary: gigi kecil di samping gigi utama.
- Toolbar mengambang: Pilih, Gambar bebas (anotasi), Warna, Hapus; Legenda; Dentisi (semua tetap/sulung/belum erupsi); Toggle 2D/3D; Cetak; Mode grid; Mode catatan.
- Grid di bawah bagan: daftar tindakan, bisa diwarnai per kategori atau per status; pilih baris -> total biaya, diskon, bagian pasien.
- Catatan: simpan draf atau finalkan (cocok dengan aturan Draf AI -> disetujui dokter).
- 2D dan 3D tersinkron (satu data); pilihan 2D/3D diingat per user. Bagan 2D untuk pilih gigi+permukaan cepat.

# Catatan: iDentalSoft (SoftwareAdvice UK, dibaca 14 Nov 2026)
Sumber: https://www.softwareadvice.co.uk/software/24447/identalsoft (deskripsi vendor + ulasan pengguna)
- Fitur yang disebut: odontogram 3D, overlay riwayat untuk presentasi kasus (naikkan penerimaan rencana perawatan), template + auto-code, tanda tangan consent/formulir lewat tablet, portal pasien, telepon masuk menampilkan data pasien otomatis.
- Keluhan pengguna yang jadi pelajaran: atur jadwal per dokter/ruang/kursi terasa "clunky" -> buat pengaturan kursi sederhana; fitur terasa berlebihan untuk user baru -> mode sederhana; tidak ada pop-up alert -> kita punya chip alergi selalu tampil + peringatan pasien.
