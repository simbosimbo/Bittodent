Mode Dokter

Sesudah. Bar Dokter, Beranda = Pasien saya. Pill pindah 200ms, konten fade 120ms keluar lalu masuk. Toast dengan Urungkan.

Mode di kodeJadwal HP (feat/jadwal-mobile, feat/motion): Meja depan | Dokter, hanya untuk dokter yang juga punya peran meja. Disimpan jadwal-mode:{user}, sinkron ke Beranda lewat event. Staging belum punya mode.
Yang berubahMode = tampilan saja: bar, Beranda, urutan menu Lainnya. Izin tetap gabungan semua peran, server tetap memeriksa. Rute yang tidak ada di mode baru pindah ke Beranda.
Ingat per perangkatlocalStorage mode:{tenant}:{user}. HP klinik bersama tetap per akun. Login pertama: default peran (dokter saja = Dokter, ada peran meja = Meja depan, pemilik saja = Pemilik).
GerakTotal 200ms atau kurang: pill transform 200ms standard, konten opacity 120ms. Sheet masuk 280ms spring. prefers-reduced-motion: ganti tanpa gerak. Mulai kunjungan tetap pindah ke Dokter otomatis + toast.
